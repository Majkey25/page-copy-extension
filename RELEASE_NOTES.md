# Page Copy 1.0.0

- Capture the full page as one PNG with **Copy to clipboard** or **Save as…**.
- Use the same minimal black and white interface as Tab Copy.
- Identify Page Copy by its dedicated camera icon.
- Load lazy content automatically, assemble small screenshot tiles locally, and restore the original scroll position.
- Keep screenshots on your device with no account, server, tracking, or runtime dependencies.

Download `page-copy-extension.zip`, extract it to a permanent folder, and load it through Developer mode in Chrome or Edge. Keep the popup open until copying finishes. Close DevTools on the source tab before capture.

Very large pages are scaled to the documented image limits. Infinite feeds, independently scrolling panels, virtualized lists, protected content, PDFs, and browser pages have limitations. See the README for details.

CI checks lint, syntax, unit tests, dependency vulnerabilities, package contents, checksums, and real Chromium capture on Linux and Windows before publishing a stable release. This GitHub release is an unpacked extension, not a Chrome Web Store listing.
